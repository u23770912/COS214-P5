TROUBLESHOOTING:
================

ERROR: "Connection refused"
---------------------------
CAUSE: C++ server not running
FIX:
  1. Start C++ server FIRST
  2. ./greenhouse → option 2
  3. Wait for "Server started on port 8765"
  4. THEN start GUI


ERROR: "Address already in use"
-------------------------------
CAUSE: Port 8765 is already taken
FIX:
  1. Kill existing greenhouse process:
     pkill greenhouse
  2. Start fresh:
     ./greenhouse → option 2


ERROR: GUI shows plants but terminal doesn't
---------------------------------------------
CAUSE: This shouldn't happen with Option B!
FIX:
  1. Make sure you selected option 2 (not option 3)
  2. Verify terminal shows "GUI Server: CONNECTED"
  3. Check terminal shows plant count increasing


ERROR: Plants not growing in terminal
--------------------------------------
CAUSE: Simulation not running
FIX:
  1. Make sure you pressed Enter after selecting option 2
  2. Terminal should update every 1 second
  3. Look for "Elapsed: Xs" counter


ERROR: "BUILD FAILED" in NetBeans
----------------------------------
CAUSE: Syntax error or missing import
FIX:
  1. Check GreenhouseAPI.java has: import java.net.*;
  2. Check no duplicate imports
  3. Clean and Build again

===========================

OLD WAY (Option A):
-------------------

BENEFITS:

  ✅ Same state as terminal
  ✅ Real-time synchronization
