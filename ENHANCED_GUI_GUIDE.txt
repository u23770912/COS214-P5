OVERVIEW:
---------
The enhanced system now includes a full-featured management GUI with 5 tabs:
1. Plant Monitor - View and manage all plants
2. Worker Management - Add and track workers
3. Customer Orders - Create orders with shopping cart
4. Dashboard - View statistics and metrics
5. Live Feed - Real-time activity log

ARCHITECTURE:
-------------
- Terminal (Option 2): Runs full autonomous simulation
  - Shows plant growth cycles
  - Displays worker activities
  - Processes orders automatically
  - Visualizes greenhouse structure

- GUI (NetBeans): Management interface
  - Add new plants dynamically
  - Hire workers
  - Create customer orders
  - Monitor system status
  - View live activity feed

USING THE ENHANCED GUI:
-----------------------

TAB 1: PLANT MONITOR
--------------------
View all plants in the greenhouse with their current state.

FEATURES:
- Table showing: ID, Name, Type, State, Price
- "Refresh" button - Update plant list
- "Add Plant" button - Create new plants
  * Opens dialog with fields: Species, Type, Pot Type, Price

WORKFLOW:

2. Select a plant to see its details

TAB 2: WORKER MANAGEMENT

TROUBLESHOOTING:
----------------

PROBLEM: GUI won't connect
SOLUTION: 
- Verify greenhouse binary is compiled: make
- Check path in MainGUI.java line ~27
- Ensure using forward slashes in path
- Try running ./greenhouse manually first

PROBLEM: "Not a valid Win32 application"
SOLUTION:
- The GUI automatically runs through WSL
- Make sure WSL is installed and working
- Path must start with /mnt/c/...

PROBLEM: ADD_PLANT fails
SOLUTION:
- Ensure all fields are filled in dialog
- Price must be valid number (use dot for decimal)
- Species/Type should be text only

PROBLEM: Orders not processing
SOLUTION:
- Make sure cart has items
- Plants must be in "ReadyForSale" state
- Check Live Feed for error messages

PROBLEM: Workers not showing
SOLUTION:
- Click "Refresh" after adding workers
- Workers are stored in StaffManager
- Check if worker was actually created in C++ backend


COMMAND REFERENCE (C++ Backend):
--------------------------------
The GUI communicates with C++ using these commands:

GET_PLANTS - Retrieve all plants
GET_STATS - Get system statistics  
ADVANCE <id> - Advance plant lifecycle
ADD_PLANT <species> <type> <pot> <price> - Create new plant
GET_WORKERS - Retrieve all workers
ADD_WORKER <name> <role> - Hire new worker
CREATE_ORDER <id1> <id2> ... - Process order with plant IDs
EXIT - Close connection
