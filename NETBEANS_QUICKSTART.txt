🎨 NETBEANS JAVA GUI SETUP
══════════════════════════════════════════════════════════════════

STEP 1: Create NetBeans Project
--------------------------------
1. Open NetBeans
2. File → New Project → Java → Java Application
3. Project Name: "GreenhouseGUI"
4. Create Main Class: Yes
5. Click Finish

STEP 2: Add API Files
----------------------
Copy these files to your NetBeans project:
  NetBeansGUI/src/greenhouse/GreenhouseAPI.java
  NetBeansGUI/src/greenhouse/MainGUI.java

In NetBeans:
1. Right-click "Source Packages"
2. New → Java Package → Name: "greenhouse"
3. Copy the two .java files into: src/greenhouse/

STEP 3: Update Executable Path
-------------------------------
In MainGUI.java, line 29, update the path:
  
  BEFORE:
    String exePath = "./greenhouse";
  
  AFTER (Windows/WSL):
    String exePath = "C:\\Users\\socce\\Documents\\COS214\\Prac5\\greenhouse";
  
  OR (Linux):
    String exePath = "/home/user/COS214/Prac5/greenhouse";

STEP 4: Run!
------------
1. Right-click MainGUI.java
2. Click "Run File" (or press Shift+F6)
3. The GUI will launch and connect to your C++ backend!

📚 AVAILABLE COMMANDS
══════════════════════════════════════════════════════════════════

Your C++ backend supports these commands:

GET_PLANTS
----------
Returns: List of all plants
Format:  PLANTS <count>
         <id>|<name>|<type>|<state>|<price>
         ...
         END

GET_STATS
---------
Returns: System statistics
Format:  STATS
         total_plants|<number>
         healthy_plants|<number>
         orders|<number>
         revenue|<amount>
         END

ADVANCE <plantId>
-----------------
Advances lifecycle of specified plant
Returns: OK <message> or ERROR <message>

EXIT / QUIT
-----------
Closes the backend gracefully

🔧 TROUBLESHOOTING
══════════════════════════════════════════════════════════════════

Problem: "Failed to connect to greenhouse system"
Solution: 
  - Check executable path is correct
  - Make sure ./greenhouse is compiled (run: make)
  - On Windows/WSL, use full path with forward slashes

Problem: GUI freezes
Solution:
  - The C++ backend may have crashed
  - Check console output for errors
  - Restart NetBeans project

Problem: Can't see plants
Solution:
  - Click "Refresh" button
  - Check that C++ backend initialized properly
