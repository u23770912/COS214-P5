\doxysubsection{Detailed Description}
Template Method Pattern\+: Abstract class defining the algorithm skeleton. 

The template method \doxylink{class_bouquet_suggestion_template_a1412212ea2f59e0cbb16419870401118}{generate\+Suggestions()} defines the structure\+:
\begin{DoxyEnumerate}
\item Display event message
\item Create standard option
\item Create premium option
\item Create budget option
\item Add event-\/specific decorations
\item Return all suggestions 
\end{DoxyEnumerate}
