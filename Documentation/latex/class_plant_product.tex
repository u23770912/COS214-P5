\doxysubsection{Detailed Description}
Main plant product class that integrates multiple design patterns. 

This class serves as the context for multiple design patterns\+:
\begin{DoxyItemize}
\item State Pattern\+: Manages plant lifecycle states
\item Observer Pattern\+: Notifies observers of plant state changes
\item Bridge Pattern\+: Abstracts plant species characteristics
\item Strategy Pattern\+: Implements different care strategies
\end{DoxyItemize}

Each plant has a unique ID, species profile, and can transition through various states during its lifecycle while receiving different types of care.
