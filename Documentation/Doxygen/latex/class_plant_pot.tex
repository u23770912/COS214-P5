\doxysubsection{Detailed Description}
Leaf node in Composite pattern representing a plant location in greenhouse. 

\doxylink{class_plant_pot}{Plant\+Pot} represents a physical location/slot in the greenhouse structure where a \doxylink{class_plant_product}{Plant\+Product} can be placed. It uses AGGREGATION (weak reference) to associate with a \doxylink{class_plant_product}{Plant\+Product}, meaning\+:
\begin{DoxyItemize}
\item \doxylink{class_plant_pot}{Plant\+Pot} does NOT own the \doxylink{class_plant_product}{Plant\+Product}
\item \doxylink{class_plant_product}{Plant\+Product} lifecycle is managed by \doxylink{class_inventory_manager}{Inventory\+Manager}
\item When \doxylink{class_plant_product}{Plant\+Product} moves to sales floor, \doxylink{class_plant_pot}{Plant\+Pot} remains empty but intact
\item \doxylink{class_plant_pot}{Plant\+Pot} can be reused for new plants
\end{DoxyItemize}
