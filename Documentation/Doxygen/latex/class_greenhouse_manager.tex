\doxysubsection{Detailed Description}
Facade for managing greenhouse structure and plant assignments. 

This class extends \doxylink{class_greenhouse_system}{Greenhouse\+System} functionality by providing\+:
\begin{DoxyItemize}
\item Easy plant addition to correct species nodes
\item Navigation through greenhouse hierarchy
\item Visualization of entire greenhouse structure with all plants
\item Plant removal when moving to sales floor
\item Statistics and reporting
\end{DoxyItemize}
