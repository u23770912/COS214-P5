\doxysubsection{Detailed Description}
Leaf node in Composite pattern that represents individual \doxylink{class_plant_product}{Plant\+Product} instances. 

This class serves as an adapter/wrapper that allows \doxylink{class_plant_product}{Plant\+Product} to participate in the \doxylink{class_greenhouse_component}{Greenhouse\+Component} tree structure through aggregation (weak association).

Key Design Decisions\+:
\begin{DoxyItemize}
\item \doxylink{class_plant_product}{Plant\+Product} is stored by POINTER (aggregation, not composition)
\item The \doxylink{class_plant_product_leaf}{Plant\+Product\+Leaf} does NOT own the \doxylink{class_plant_product}{Plant\+Product}
\item When \doxylink{class_plant_product}{Plant\+Product} moves to sales floor or withers, this leaf can be removed from the tree without deleting the \doxylink{class_plant_product}{Plant\+Product}
\item The \doxylink{class_greenhouse_component}{Greenhouse\+Component} structure (Category/\+Type/\+Species) remains intact and can be reused for new plants
\end{DoxyItemize}

Lifecycle\+:
\begin{DoxyEnumerate}
\item \doxylink{class_plant_product}{Plant\+Product} created with species profile
\item \doxylink{class_plant_product_leaf}{Plant\+Product\+Leaf} created referencing the \doxylink{class_plant_product}{Plant\+Product}
\item Leaf added to appropriate Species node in greenhouse structure
\item When \doxylink{class_plant_product}{Plant\+Product} reaches Ready\+For\+Sale or Withering\+:
\begin{DoxyItemize}
\item Leaf removed from tree (\doxylink{class_inventory_manager}{Inventory\+Manager} owns \doxylink{class_plant_product}{Plant\+Product})
\item \doxylink{class_greenhouse_component}{Greenhouse\+Component} structure unchanged and reusable 
\end{DoxyItemize}
\end{DoxyEnumerate}
