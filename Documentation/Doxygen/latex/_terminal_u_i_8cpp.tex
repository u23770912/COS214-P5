\doxysubsection{Detailed Description}
Implementation of the \doxylink{class_terminal_u_i}{Terminal\+UI} class for all terminal UI operations. 

This class provides two categories of functionality\+:
\begin{DoxyEnumerate}
\item System-\/wide display utilities (used by main.\+cpp for greenhouse simulation)
\item Customer-\/facing operations (used by Customer/\+Order system for sales)
\end{DoxyEnumerate}

The \doxylink{class_terminal_u_i}{Terminal\+UI} acts as a central Facade for all terminal display operations, ensuring consistent formatting and color coding throughout the application.
