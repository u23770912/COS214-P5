\doxysubsection{Detailed Description}
Memento object for storing \doxylink{class_order}{Order} state snapshots. 

This class holds an opaque string representation of an \doxylink{class_order}{Order}\textquotesingle{}s state so the caretaker can save and restore order snapshots without exposing the internals of the \doxylink{class_order}{Order} class.
