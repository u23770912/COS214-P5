\doxysubsection{Detailed Description}
Director class for the Builder Design Pattern. 

The \doxylink{class_order_director}{Order\+Director} encapsulates the construction logic for different types of orders. It coordinates the step-\/by-\/step building process through the Builder interface, allowing the \doxylink{class_customer}{Customer} to simply call \doxylink{class_order_director_af091c3f5b5aab7a6c1542d6a3aa211da}{construct()} without managing the building details.
