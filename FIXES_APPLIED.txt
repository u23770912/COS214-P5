WHAT HAPPENS NOW:
-----------------

1. You add plant in GUI
   ↓
   GUI calls: api.addPlant("Rose", "Flower", "Clay", 25.99)
   ↓
   Java sends: "ADD_PLANT Rose Flower Clay 25.99"
   ↓
   C++ creates: new FlowerProfile + new PlantProduct
   ↓
   C++ adds to: InventoryManager.addToGreenhouse()
   ↓
   C++ responds: "OK Plant_0 created successfully"
   ↓
   GUI adds to table: [0, Rose, Flower, Planted, $25.99]
   ↓
   GUI logs feed: "Created new plant: Plant_0 (Rose)"
   ↓
   Terminal simulation: Sees new plant, starts processing it

2. You click "Refresh"
   ↓
   GUI calls: api.getAllPlants()
   ↓
   Java sends: "GET_PLANTS"
   ↓
   C++ reads: InventoryManager.getGreenHouseInventory()
   ↓
   C++ returns: All plants with current states
   ↓
   GUI updates table: Shows live data
